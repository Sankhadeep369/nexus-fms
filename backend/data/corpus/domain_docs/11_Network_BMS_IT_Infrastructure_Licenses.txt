# 1. Purpose

Maintains the digital backbone that supports building automation, connectivity, and licensed software operations.

# 2. Scope

Includes BMS front ends, controllers, switches, access points, servers, CCTV-network interfaces, licenses, backups, and access rights.

# 6. Records, Logs, and Registers

BMS alarm log, network fault log, license register, backup confirmation, access matrix, change request register

# 7. Precautions and Critical Controls

Never share admin credentials; change only through approved window; back up before updates; document every controller swap or IP change; maintain vendor support evidence; ensure cyber and physical protection of comms rooms.

# 8. Escalation and Incident Response

| Severity | Trigger | Action | Escalation |
| --- | --- | --- | --- |
| Medium | System degradation or alarm burst | Monitor and restore from backup path | BMS Coordinator |
| High | Loss of monitoring to critical assets | Escalate to IT/OEM and apply workaround | Facilities Manager |
| Critical | Security breach or total system outage | Isolate access and invoke incident plan | IT Lead + Management |
